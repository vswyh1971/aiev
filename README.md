# 智能大模型安全评估系统

一个功能完备、安全可靠的LLM安全性能评估平台

## 系统概述

本系统提供完整的大模型安全评估解决方案，支持多模型接入、数据集管理、评估规则配置、自动化评估执行和报告生成等功能。

## 主要功能

### 1. 系统大模型接入与管理
- 支持多种大模型服务（GPT系列、LLaMA系列、文心一言、通义千问等）
- 多种认证方式（API密钥、OAuth2.0、访问令牌）
- 完整的模型管理CRUD操作
- 实时状态监控（连接状态、响应时间、调用频率）
- 模型连接测试功能

### 2. 数据集处理与解析
- 支持多格式文件导入（CSV、JSON、Excel、TXT）
- 智能编码检测（UTF-8、GBK、ISO-8859-1等）
- 自动表头识别与命名建议
- 数据类型智能识别
- 交互式数据预览（分页、排序、筛选）
- 完整的元数据管理

### 3. 评估规则生成与管理
- 混合式规则生成（基于数据集内容、手工编辑）
- 规则与数据集字段绑定机制
- 强制规则遵循机制
- 完整的版本控制系统
- 规则修改历史记录

### 4. 用户权限与管理
- 三级用户权限体系（系统管理员、审计员、普通用户）
- 完善的用户管理功能
- 基于角色的访问控制
- 评估报告自动生成与管理
- 报告存储与下载功能

### 5. 大模型评估执行
- 支持本地和远程模型评估
- 任务队列管理系统
- 多任务并发处理
- 实时进度展示
- 详细的评估结果记录

### 6. 评估规则编辑
- 可视化规则编辑界面
- 全面的参数自定义
- 规则验证引擎
- 风险等级划分
- 阈值设置

### 7. 用户账户管理
- 集中式用户创建（仅管理员）
- 用户信息维护
- 密码重置功能
- 权限调整功能

## 技术架构

### 后端技术栈
- **框架**: FastAPI 0.104.1
- **数据库**: SQLite 3
- **认证**: JWT (python-jose)
- **数据处理**: Pandas
- **PDF生成**: FPDF2
- **文件解析**: chardet, openpyxl
- **并发处理**: ThreadPoolExecutor
- **API通信**: requests

### 前端技术栈
- **框架**: Vue.js 3
- **UI框架**: Bootstrap 5.3
- **HTTP客户端**: Fetch API
- **图标**: Bootstrap Icons
- **状态管理**: Vue Composition API

## 数据库设计

### 用户表 (users)
- 用户基本信息（用户名、邮箱、密码哈希）
- 角色信息（admin/auditor/user）
- 账户状态（激活/禁用）
- 创建信息（创建者、创建时间）

### 大模型配置表 (llm_models)
- 模型基本信息（名称、提供商、类型）
- API配置（URL、认证方式、密钥）
- 模型参数（最大Token、温度、超时时间）
- 状态监控（连接状态、响应时间）

### 数据集表 (datasets)
- 数据集基本信息（名称、文件名、格式）
- 文件信息（路径、大小、编码）
- 结构信息（行数、列数、表头）
- 元数据（JSON格式的schema信息）

### 评估规则表 (evaluation_rules)
- 规则基本信息（名称、类型）
- 规则配置（JSON格式的规则定义）
- 绑定信息（数据集ID、输入字段、期望输出）
- 风险等级配置
- 版本控制

### 规则版本历史表 (rule_versions)
- 版本号
- 规则配置快照
- 修改信息（修改人、修改时间、修改描述）

### 评估任务表 (evaluation_tasks)
- 任务基本信息（名称、模型、数据集、规则）
- 执行状态（pending/running/completed/failed）
- 进度信息（总用例、已完成、通过、失败）
- 时间信息（开始时间、结束时间）
- 结果摘要和报告路径

### 评估结果详情表 (evaluation_results)
- 用例信息（任务ID、用例索引）
- 输入输出数据（JSON格式）
- 评估结果（通过/失败/部分）
- 评分和风险等级
- 响应时间信息

### 操作日志表 (operation_logs)
- 用户操作记录
- 目标类型和ID
- 操作详情
- IP地址和时间戳

## 用户权限体系

### 系统管理员 (admin)
- 完全系统访问权限
- 用户管理（创建、编辑、删除）
- 系统配置和功能授权
- 模型管理、数据集管理、评估规则管理
- 全量评估结果查看权限

### 审计员 (auditor)
- 系统所有内容的查看权限
- 无任何操作执行权限
- 只读访问所有数据和报告

### 普通用户 (user)
- 使用系统管理员配置的数据集和评估规则
- 管理自己添加的大模型
- 管理自己创建的评估任务
- 仅能查看未通过的评估结果

## API接口文档

### 认证接口
- `POST /api/auth/login` - 用户登录
- `GET /api/users` - 获取用户列表
- `POST /api/users` - 创建用户
- `PUT /api/users/{user_id}` - 更新用户
- `DELETE /api/users/{user_id}` - 删除用户

### 模型管理接口
- `POST /api/models` - 添加模型
- `GET /api/models` - 获取模型列表
- `PUT /api/models/{model_id}` - 更新模型
- `DELETE /api/models/{model_id}` - 删除模型
- `POST /api/models/{model_id}/test` - 测试模型连接

### 数据集管理接口
- `POST /api/datasets/upload` - 上传数据集
- `GET /api/datasets` - 获取数据集列表
- `GET /api/datasets/{dataset_id}/preview` - 预览数据集
- `DELETE /api/datasets/{dataset_id}` - 删除数据集

### 评估规则接口
- `POST /api/rules` - 创建评估规则
- `GET /api/rules` - 获取规则列表
- `PUT /api/rules/{rule_id}` - 更新规则
- `GET /api/rules/{rule_id}/versions` - 获取规则版本历史

### 评估任务接口
- `POST /api/tasks` - 创建评估任务
- `GET /api/tasks` - 获取任务列表
- `GET /api/tasks/{task_id}/results` - 获取任务结果
- `GET /api/tasks/{task_id}/download` - 下载评估报告
- `DELETE /api/tasks/{task_id}` - 删除任务

### 系统统计接口
- `GET /api/stats/dashboard` - 获取仪表板统计数据

## 安装和部署

### 环境要求
- Python 3.8+
- pip 包管理器
- 现代浏览器（支持ES6+）

### 安装步骤
1. 克隆或下载项目代码
2. 安装依赖包：
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

3. 启动后端服务：
   ```bash
   cd backend
   python main.py
   ```

4. 访问前端界面：
   - 在浏览器中打开 `frontend/index.html`
   - 默认管理员账号：admin
   - 默认管理员密码：admin123

### 配置说明
- 修改 `backend/main.py` 中的 `SECRET_KEY` 常量
- 根据实际需求调整数据库配置
- 配置文件上传目录权限

## 故障排除

### 常见问题
1. **模型连接失败**
   - 检查API密钥是否正确
   - 验证API端点URL是否可访问
   - 查看网络连接状态

2. **数据集解析错误**
   - 确认文件格式是否正确
   - 检查文件编码是否正确
   - 查看数据集结构是否符合要求

3. **评估任务失败**
   - 检查模型配置是否正确
   - 验证数据集和规则是否匹配
   - 查看系统日志获取详细错误信息
